# Train-Ticket-Reservation-System
Overview

This Java project implements a Train Ticket Reservation System that allows users to search for trains, check seat availability, book tickets, view booked tickets, and cancel reservations. It demonstrates key concepts of Object-Oriented Programming (OOP), file/database handling, and console-based user interaction.

Features

Search trains by number or route

Check seat availability

Book tickets

View passenger details

Cancel tickets

Admin options (optional)

Data stored using files or a database

Technologies Used

Java (Core Java / OOP)

File Handling or MySQL Database (based on implementation)

IDE: Eclipse / IntelliJ / NetBeans (optional)

How to Run

Clone or download the project.

Open the project in any Java-supported IDE.

Ensure required files or database tables are set up.

Compile and run the Main.java file.

Follow on-screen instructions in the console menu.
